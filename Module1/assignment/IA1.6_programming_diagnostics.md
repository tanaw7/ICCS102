## Part 2 - Pseudocode

A shop asks for the price of one item and the quantity purchased.

The program should:

* calculate the total price;
* apply a 10% discount if the total price is at least 1,000 baht; and
* display the final price.

Write pseudocode or clear step-by-step instructions for this program. Do not write Python code for this part.

## Part 3 - Code Tracing

For each program, write its exact output without running the code.

### Program A

```python
x = 7
y = 3
x = x + y
y = x * 2

print(x)
print(y)
```

### Program B

```python
score = 68

if score >= 80:
    print("Excellent")
elif score >= 60:
    print("Pass")
else:
    print("Try again")
```

### Program C

```python
total = 0

for number in range(1, 5):
    total = total + number

print(total)
```

## Part 4 - Python Program

Create one Python program. Complete as many stages as you can.

### Stage 1

1. Ask the user for their name.
2. Display a greeting containing the name.

### Stage 2

3. Ask for three quiz scores.
4. Calculate the average score.
5. Display the student's name and average score.

### Stage 3

6. Display `Pass` if the average is at least 60, or `Needs Improvement` otherwise.

Write, save, and test the program in PyCharm.

If your program is unfinished or does not run correctly, submit the `.py` file containing your attempt. Do not delete your work or replace it with copied code.

## Optional Challenge
