# Assignment 1.5: Reading Assignment Instructions Carefully

## Assignment Type

Individual reading-comprehension and course-responsibility assignment

## Learning Objectives

By completing this assignment, students should be able to:

* locate important information in an assignment specification,
* identify deadlines and submission requirements,
* identify whether an assignment is individual or group work,
* identify required file types and naming formats,
* identify where work must be submitted,
* recognize that reading assignment instructions is part of the student's responsibility.

## Duration

Recommended working time: **15–20 minutes**

## Task Description

University assignments often contain several instructions that must be followed together.

For this exercise, read the assignment page provided by your instructor on GitHub.

Do not answer from memory and do not guess.

Read the page carefully and answer the questions below using information from the assignment instructions.

### Questions

1. What is the **deadline** for the assignment?
2. Is the assignment **individual work, group work, or both**?
3. What **file type or file types** must be submitted?
4. What is the required **file naming format**?
5. Where must the completed work be **submitted**?
6. Identify **one additional requirement** from the assignment that a student could easily miss if they did not read the instructions carefully.

For each answer, write the answer clearly and briefly.

Where appropriate, copy exact technical information such as a required filename or file extension.

The purpose of this task is simple: important assignment information is normally provided before the deadline. Students are responsible for reading the instructions that are provided.

## AI Policy

**No AI assistance is allowed for this assignment.**

Do not use ChatGPT, Gemini, Claude, or any other generative AI tool to read the assignment page for you, extract the answers, summarize the instructions, or answer the questions.

The purpose of this exercise is to demonstrate that **you can read an assignment specification and locate important information yourself**.


## Submission and File Naming Format

Answer the six questions directly in the **Google Classroom assignment comment** unless your instructor provides a different submission location.

No uploaded file is required.

### File Naming Format

No file naming format is required because no file is uploaded.
