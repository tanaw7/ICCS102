# Module 3 - Review Questions

1. **Basic programming constructs**
   - What are the three basic programming constructs? Describe each briefly.

2. **Iteration**
   - What is iteration in programming? Briefly discuss its two types.
   - Give a real-life example of each type. You do not need to write algorithms; descriptions of the scenarios are enough.

3. **Count-controlled iteration**
   - What is count-controlled iteration?
   - What are its benefits?

4. **Condition-controlled iteration**
   - What is condition-controlled iteration?
   - What are its benefits?

5. **Subroutines**
   - What are subroutines? Why are they useful?

6. **Flowcharts**
   - Identify the flowchart symbols and arrangements used to represent each basic programming construct.

7. **Pseudocode**
   - Identify the keywords and structures used to represent each basic programming construct in pseudocode.

8. **Nesting**
   - What is nesting?
   - Give an example and clearly explain how nesting is used.

9. **Decomposition**
   - What is the result of breaking down a problem?
   - How does writing steps for computational thinking differ from writing general instructions for daily routines, such as cooking fried rice or studying for a quiz?

10. **Output and testing tables**
    - What are the purposes of the output table and testing table in the “Design an Algorithm” examples?

11. **Planning before coding**
    - Why should we develop algorithms using flowcharts, pseudocode, or similar methods before writing code? You may need external resources to answer this question.

12. **Python**
    - What is Python?
    - Why is Python chosen for this course and many introductory programming courses around the world?

13. **Types of numbers**
    - List the numeric types in Python and describe each.
    - Give examples of each type.

14. **Floating-point numbers**
    - Why do Python and many other programming languages use floating-point representation for real numbers? Research this question independently.

15. **More data types**
    - What are strings? Give a couple of examples of strings in an algorithm or Python.
    - What are Booleans? Give a couple of examples of Boolean values or expressions in an algorithm or Python.

16. **Your first function in Python**
    - What does the `print` function do?
    - Is `print` a subroutine? Explain your answer.
    - Why does `Print(45)` fail in Python if `Print` has not been defined? How would you fix it?
    - What does `print(3,123)` do?
